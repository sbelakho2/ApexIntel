{# ── Change Password ───────────────────────────────────────────────────────── Self-service credential rotation for the signed-in account. Included by pages/settings.html. Posts to `/settings/password` under the self-service guard (session + CSRF). The server verifies the current password, rehashes with Argon2id, bumps `session_version` (signing out the user's other sessions), and reissues this browser's cookie. Markup follows the canonical Sensei-Rams form pattern (`.apex-input`, `.apex-btn apex-btn-primary`, micro-label headings). #}
