## B. Page-specific problems

### Login (00)
- Content is crammed into the right half; left 55% of the viewport is empty in both themes (looks broken, not intentional).
- `Access Platform` button label is marketing-speak; fields `Operator ID` / `Access Key` obscure that this is username/password.
- Two theme toggles rendered (top + bottom).

### Dashboard "DECISIONS" (01)
- h1 `Decisions` tells the operator nothing; the page is an overview.
- Two stacked stat-card rows (4 + 5 cards) with overlapping metrics (ACTIVE WARNINGS appears in row 1 and REQUIRES ACTION; DATA FRESHNESS card renders a huge sentence instead of a number; PORTFOLIO HEALTH text card).
- `WHAT IS STALE OR BROKEN` rows inconsistently styled (one row has a red left rail, others don't; BROKEN row renders half-clipped at default viewport).
- RECENT ACTIVITY shows 12 identical `BATTLECARD regenerated` rows — noise, no dedupe/grouping.
- Footer strip duplicates header badges and the second strip repeats the first.

### Warnings (02, 03)
- See A2/A4. Table column header `CREATE` truncated; CREATED dates truncated; table horizontally scrolls.
- Warning detail: 6 forms on one page; action buttons (Acknowledge/Investigate/Analyze) each with their own form + status region — no clear primary action ordering; long page with repeated status blocks.

### Insights (04, 05)
- `USE AI` button unexplained; h1 giant; A2/A3/A4/A8.
- Insight detail: Bookmark is the primary (filled) action while Briefing/Analyze are secondary — inverted priority; 64px 3-line title pushes all content below the fold.

### Companies / Persons / Buying centers (06, 07, 10–12)
- QUICK LINKS card mostly empty; narrative cards row widths uneven (2nd card wider, dead space right).
- Company detail repeats the same warning 4× (EVIDENCE TIMELINE ×2, RISKS, ALL WARNINGS) and the insight 2× on one page; ~14 stacked modules with no navigation; WATCH ALERTS form mid-page; SUPPLY CHAIN header clipped.
- Person detail: generic `POI PROFILE` h1 while the person's name is an h2; UUID + `COPY` + `JUMP TO: POI PROFILE` cruft above the identity; WATCH ALERTS form above the name.
- POI priority vector bars use 4 arbitrary colors (red/blue/yellow/green) with no legend.

### Competitors (13)
- No header module; AVG metrics show `—` as large numerals; page 75% empty below the fold.

### Battlecards (14–18)
- List cards ~35% width with dead space; no visible view/edit affordances; `0 of 9 sections` is opaque.
- New battlecard: 3 fields, then nothing — no explanation of the 9 sections or next step; Compare page needs pre-selected ids to be useful.

### Graph (19)
- Control panel is a wall of jargon (`PROGRESSIVE DISCLOSURE: DEFAULT: SELECTED ENTITY + FIRST-DEGREE…`, `WEAK EDGES`, `OVERVIEW SLICE`) in caps chips.

### Recipes (20, 21)

## D. Revamp direction (implemented in this change set)
1. **One design language**: single `page_header` (sentence-case, 28–32px), module cards with compact headers, one filter-bar component, one table style, one empty-state component; caps only for micro-labels (10–11px) where they aid scanning.
2. **Semantic color only**: kill rainbow card borders; accents reserved for state (active nav rail, severity badges, primary CTA). Numbers use tabular numerals.
3. **De-duplicate lists**: card list is the single source (tables removed from list pages); counts + trends live in one stat row.
4. **Filters**: one toolbar — inline auto-apply search (HTMX), grouped `<select>`s for enums, count badges, one Reset; no Apply button.
5. **Shell**: brand once (sidebar), header = search + theme + alerts + user menu (admin inside); remove fake ⌘K; one slim status strip (11px) merging system/data health.
6. **Detail pages**: identity first (name h1, meta chips), sticky anchor sub-nav for long pages, actions in one toolbar, watch-alerts and notes below the fold, relationships de-duplicated.
7. **Forms**: structured rows instead of JSON textareas (recipe builder), fixed labels above inputs (Rams), inline validation, honest helper text; no dev-facing copy.
8. **Notifications**: server-side pagination + unread filter + mark-all.
9. **Charts**: hide all-zero series, ≥10px axis text, fix activity-chart fill bug, fix donut/mention labels.
10. **Empty states**: one component (icon + statement + next action) instead of four stacked empties (security) or blank expanses (competitors, workspaces).
