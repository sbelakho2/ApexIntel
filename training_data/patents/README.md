# Patents Classification Data

## Purpose
This directory is intended to hold patent classification data (e.g., CPC — Cooperative Patent Classification codes, IPC — International Patent Classification codes) for training entity extraction and classification models on patent-related content.

## Planned Data
- **CPC codes** (Cooperative Patent Classification) — hierarchical classification system for patents
- **IPC codes** (International Patent Classification) — global patent classification system
- **USPC codes** (United States Patent Classification) — legacy US classification codes

## Status
Currently empty. Patent classification data should be downloaded from:
- **CPC:** https://www.cooperativepatentclassification.org/
- **IPC:** https://www.wipo.int/classifications/ipc/
- **USPTO:** https://www.uspto.gov/web/patents/classification/

## Note
This directory is preserved for future data collection. Scripts referencing this directory should handle the empty state gracefully.
