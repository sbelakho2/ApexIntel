# World Bank Logistics Performance Index (LPI) — 2007–2023

## Source
- **Dataset:** Logistics Performance Index (LPI)
- **World Bank API:** https://api.worldbank.org/v2/indicator/LP.LPI.OVRL.XQ?format=excel
- **Website:** https://lpi.worldbank.org/

## Download Instructions
1. Visit the World Bank API endpoint above, or
2. Go to https://lpi.worldbank.org/ and navigate to the data/download section
3. The file should be a valid Excel (`.xlsx`) file with magic bytes `PK\x03\x04`
4. Save as `world_bank_lpi_2007_2023.xlsx` in this directory

## Metadata
| Field | Value |
|-------|-------|
| Indicator | LP.LPI.OVRL.XQ — Logistics Performance Index: Overall (1=low to 5=high) |
| Coverage | ~160 countries, 2007–2023 (biennial: 2007, 2010, 2012, 2014, 2016, 2018, 2023) |
| License | CC BY 4.0 (World Bank requires attribution) |
